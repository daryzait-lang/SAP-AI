# Objetivo
Construir frontend UI5 empresarial con patrones Fiori y libertad visual controlada.

# Reglas
- Separar View, Controller, models y services.
- Consumir exclusivamente APIs del backend ASP.NET Core.
- No colocar credenciales SAP en el navegador.
- Diseñar responsive desktop/tablet.
- Mantener estados loading/error/empty/success.
- Priorizar accesibilidad, consistencia, rendimiento y mantenibilidad.
- Generar routing, fragments y componentes reutilizables cuando aporten valor.
